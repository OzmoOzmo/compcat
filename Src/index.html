ABOUT THIS TOOL

Built for your electronics bench

Component Log helps organize the parts you capture with your phone camera.

⌗

Markings, not magic

Browser OCR reads visible package markings. The result is a starting point for your review, not a guaranteed identity. Verify datasheets before relying on pinouts or ratings.

▣

Saved on this device

Session scans, archived parts, and photos stay in this browser's IndexedDB; the optional AI key uses local storage. Clearing site data removes them. There is no account or cloud sync.

◈

AI details are optional

Gemini can look up extra information when configured. Your key is sent to Google only when you request details. Review AI answers against manufacturer sources.

Recognition limits

Small, worn, rotated, shadowed, or low-contrast markings can be misread. The current scanner handles one or more visible components in still photos; multi and continuous video modes are planned.

Browser-based component inventory · No installation required

This static app cannot protect a secret like a server can. Your saved key is accessible to this app and browser environment. Use a restricted key, manage quotas, and remove it when finished.
